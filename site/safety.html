Safety and recovery

ModSync checks before it changes anything, keeps a copy while it works, and stops at the first problem. Here is what that means for your game folder.

Validation changes nothing

Validation runs the whole install in memory. It keeps track of which files each step would add, move or remove, so a later step can rely on an earlier one. It looks inside archives using private temporary files outside your game and mod folders.

  • It never changes your game folder or your mod folder.
  • It never runs patchers or other programs.

That second point has a cost: validation cannot know what a patcher will do. It may report a problem with a later step that needs a file a patcher would have created, and a clean report is not a promise that a patcher will succeed.

A snapshot before every install

Installing always validates first. Then ModSync locks both folders and copies them: the game folder and the mod folder. The copy is kept next to your game folder, in a folder named .modsync- followed by an ID.

Because these are full copies, you need enough free space for both folders. The copy from your last successful install stays until the next install.

Do not use other tools on the folders while it works. The lock only coordinates ModSync itself. Leave the game and mod folders alone until the install or restore finishes.

If an install fails

ModSync stops at the first failure and leaves a marker saying an install is unfinished. Until you restore, it will not start another install on top of the half-finished one.

In the desktop, use Restore on the progress page. From the command line:

modsync restore --game-dir /path/to/game --source-dir /path/to/mods

Restore checks the snapshot against its recorded fingerprints before it touches either folder, puts the files back, then checks the restored files again.

Then start again from the top

Once restored, fix whatever caused the failure (often a missing or wrong archive) and run the install again from the start, in the guide's order.

Never tack a failed mod onto the end. Mods later in a build often overwrite or build on files from earlier ones. Installing an early mod last can undo later mods or break the game. Restore and rerun the whole guide instead.

What the snapshot is not

  • Not a backup. Keep your own copy of anything valuable, such as save games.
  • Not per mod. There is one snapshot for the whole run. You cannot resume from the middle or undo a single mod.
  • Not an undo for finished installs. restore is only for an install that did not finish.
  • Not power-cut proof. It is not an all-or-nothing transaction if the computer loses power mid-install.

Other safeguards

Stays inside your two folders
Instructions refer to the game folder and the mod folder by name, and anything that points outside them is refused. So are links, device names, paths that climb out with .., names that differ only by capital letters, and game and mod folders that overlap.
Refuses what it does not understand
An unknown instruction or field stops the guide instead of being skipped. A mod with no instructions cannot be installed.
Outside programs are opt-in
Patchers and other programs only run when you allow them, and they never run during validation.
Downloads are checked
Direct downloads must be real archives with the expected checksum, and never overwrite a file you already have.
Temporary space you choose
Archives are unpacked through temporary storage. You can point that at a different drive and set a size limit per archive, under Archive storage in the desktop or with --scratch-dir and --max-expanded-bytes.
