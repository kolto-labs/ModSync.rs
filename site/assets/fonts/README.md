# Site typefaces

The site uses the Kolto Labs homepage type pairing at
https://koltolabs.bodecloud.workers.dev/: Departure Mono for display and utility
text, IBM Plex Sans for reading, and IBM Plex Mono for code. WOFF2 files are
served locally so the site also works without a Google Fonts connection.

- Departure Mono Regular by Helena Zhang and Tobias Fried, downloaded from the
  Kolto Labs site. Source: https://github.com/rektdeckard/departure-mono.
  License: `departure-mono-LICENSE.txt` (MIT).
- IBM Plex Sans Regular, downloaded from the Kolto Labs site. IBM Plex Sans
  Semibold and IBM Plex Mono Regular are the Latin WOFF2 distributions from
  https://www.npmjs.com/package/@fontsource/ibm-plex-sans and
  https://www.npmjs.com/package/@fontsource/ibm-plex-mono, served by jsDelivr.
  Source: https://github.com/IBM/plex.
  License: `ibm-plex-LICENSE.txt` (SIL Open Font License 1.1).

The adjacent `kolto-labs.svg` is the pixel K favicon from the Kolto Labs site.
The ModSync M mark retains its original shape with the shared blue/cyan palette.

## Classic theme

The optional Classic theme restores the original PR #83 type pairing:
Instrument Sans Regular, Medium, and Semibold, and Instrument Serif Italic.
Latin WOFF2 files are distributed by @fontsource/instrument-sans and
@fontsource/instrument-serif via jsDelivr. Both are licensed under SIL OFL 1.1;
see `instrumentsans-LICENSE.txt` and `instrumentserif-LICENSE.txt`.
Upstream sources and licenses: https://github.com/google/fonts/tree/main/ofl/instrumentsans
and https://github.com/google/fonts/tree/main/ofl/instrumentserif.
