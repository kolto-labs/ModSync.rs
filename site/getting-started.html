ModSync/For players/Getting started

Getting started

Get ModSync, pick a community mod build in the desktop app, check it and install it.

Before you start

You need four things:

  • KOTOR 1 or KOTOR 2 installed. ModSync works on your game folder, the one that holds the Override folder.
  • A mod build. The KOTOR Community builds are already listed in the desktop app. For any other build, you need its instruction file, which the guide author publishes. It tells ModSync which mods are in the build and how each one installs.
  • A folder for the mod downloads. ModSync does not come with any mods. The desktop app downloads them into one folder for you; on the command line you put the archives there yourself.
  • Free disk space. Room for the downloads, for unpacking them, and for the restore point ModSync keeps of your game folder so it can put it back if something fails.

Keep your own backup. The restore point is there to undo a failed install, not to replace a backup. Copy your game folder somewhere safe before your first big install.

Get ModSync

Ready-made downloads are published on the Releases page when a release is available. The downloads are not code-signed yet, so Windows or macOS may ask you to confirm the first time you open one.

If there is no download for your system yet, build it yourself. It takes one command once the tools are installed.

Build it from source

Install Rust (the stable version) and a C/C++ build toolchain:

  • Windows: the MSVC C++ build tools, and the WebView2 runtime (already part of Windows 10 and 11).
  • macOS: the Xcode command-line tools.
  • Linux: a C/C++ compiler and the WebKitGTK libraries Tauri needs.

The desktop app also needs Node.js 20 or newer. It lives in desktop/tauri:

git clone https://github.com/kolto-labs/ModSync.rs.git
cd ModSync.rs/desktop/tauri
npm install
npx tauri build --no-bundle

The app is written to desktop/tauri/src-tauri/target/release. If you only want the command line tool, see Command line.

Try it on sample folders first

The source comes with a tiny sample guide, examples/demo.toml. It copies one texture into a pretend game folder and removes an older file with the same name. These are made-up files, not game assets, so nothing real is touched. From the top of the source folder:

mkdir -p demo-work/game/Override demo-work/mods
printf 'sample texture\n' > demo-work/mods/sample.tga
printf 'old texture\n' > demo-work/game/Override/sample.tpc
cargo run -- validate --input examples/demo.toml --game-dir demo-work/game --source-dir demo-work/mods
cargo run -- install  --input examples/demo.toml --game-dir demo-work/game --source-dir demo-work/mods

Validation reports what would change without touching anything. After the install, demo-work/game/Override holds sample.tga, and the conflicting sample.tpc is gone.

Install a build in the desktop app

1. Set up

The first time you open the app, it offers to find your game, sign in to DeadlyStream and add a Nexus Mods key. Every step can be skipped and done later in Settings. Signing in to DeadlyStream is optional.

2. Pick a build and your mods

On Builds, choose a build from the list and click Refresh list. Tick the mods you want, or use Select all. Click a mod to see its description, screenshots, options and the mods it needs. Builds that are not in the list can be added with Add build or Open file.

3. Check

Click Check. The app downloads the mods, works out how each one installs, and tests the whole install without changing your game. Check results lists any problem, such as a file it could not download. Fix what it finds, then check again.

4. Install

When the check passes, click Install. Each mod is marked as it finishes. Pause and Resume hold and continue the install between mods, and Stop ends it at the next safe point. If an install does not finish, the Builds screen offers Restore to put your game back. See Safety and recovery.

The Desktop app page covers every screen, and the walkthrough goes through a full build step by step.

Getting the mods

Most KOTOR mods live on DeadlyStream or Nexus Mods. The desktop app downloads them when you check a build:

  • DeadlyStream works without an account where the site allows it. Sign in under Settings > Account for files that need one.
  • Nexus Mods needs your API key. Free accounts click Mod Manager Download on each mod's Nexus page and the app catches the link. Premium accounts download without the clicks.
  • Anything the app cannot fetch is listed with a link to download in your browser.

Downloads are checked before they are saved: a web page instead of an archive, a damaged archive or a wrong checksum fails, and an existing file is never overwritten.

Mods that use a patcher

Many KOTOR mods come with a TSLPatcher-style installer instead of plain files. ModSync runs that patch step for you. In the desktop app, Let mods run their patcher or installer under Settings > Patcher is on by default, because most builds need it, and Patcher for TSLPatcher mods chooses which patcher program to use. On the command line, outside programs only run when you add --allow-processes.

Windows programs need a Windows computer. ModSync does not run them through Wine for you.

Save your setup

The desktop app remembers your game installs, download folder and settings between launches. Each game install under Settings > Game Installs is a saved ModSync profile, and Set active switches between them.

On the command line, modsync profile saves and activates the same profiles. See the CLI reference.
