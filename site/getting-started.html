ModSync.rs/For players/Getting started

Getting started

Get ModSync.rs, try it on sample folders, then install a real mod build from its guide.

Before you start

You need four things:

  • KOTOR 1 or KOTOR 2 installed. ModSync.rs works on your game folder, the one that holds the Override folder.
  • The instruction file for a build. Guide authors publish it with their mod build. It tells ModSync.rs which mods are in the build and how each one installs.
  • The mod archives, downloaded into one folder. ModSync.rs does not come with any mods. Download each one from the page the guide links to and keep them together.
  • Free disk space. Before it installs, ModSync.rs makes a full copy of your game folder and your mod folder, so it can put them back if something fails.

Keep your own backup. The snapshot is there to undo a failed install, not to replace a backup. Copy your game folder somewhere safe before your first big install.

Get ModSync.rs

Ready-made downloads are published on the Releases page when a release is available. Packages are marked as unsigned pre-releases, so Windows or macOS may warn you the first time you open one.

If there is no download for your system yet, build it yourself. It takes one command once the tools are installed.

Build it from source

Install Rust (the stable version) and a C/C++ build toolchain:

  • Windows: the MSVC C++ build tools.
  • macOS: the Xcode command-line tools.
  • Linux: a C/C++ compiler, plus an X11 or Wayland session with OpenGL for the desktop app. File dialogs use the desktop portal.

Then download the source and start the desktop app:

git clone https://github.com/ChristopherVR/ModSync.rs.git
cd ModSync.rs
cargo run --release

The default build includes the desktop app. If you only want the command line tool, see Command line. No .NET runtime is needed.

Try it on sample folders first

The source comes with a tiny sample guide, examples/demo.toml. It copies one texture into a pretend game folder and removes an older file with the same name. These are made-up files, not game assets, so nothing real is touched.

mkdir -p demo-work/game/Override demo-work/mods
printf 'sample texture\n' > demo-work/mods/sample.tga
printf 'old texture\n' > demo-work/game/Override/sample.tpc
cargo run -- gui --input examples/demo.toml \
  --game-dir demo-work/game --source-dir demo-work/mods

In the app, choose the mods, run validation, read the report and install. Afterwards demo-work/game/Override holds sample.tga, and the conflicting sample.tpc is gone.

Install a build in the desktop app

1. Load the guide and choose your folders

On Load guide, open the build's instruction file and choose your game folder and your mod folder. Tick Save directories for next launch if you want them filled in next time.

2. Pick your mods

On Choose mods, tick the mods you want. To save time:

  • Filter by tier or category, then use Select through tier or Select category. Tiers add up: choosing tier 2 also selects tier 1.
  • Select multiple categories… lets you tick several categories and apply them together.
  • Mods that a selected mod depends on are added for you, and the changes are logged.
  • Spoiler-free names and descriptions swaps in text without plot details where the guide provides it.

3. Validate

Run validation. It walks through the whole install without changing anything and reports any problem, such as a missing archive. You can also run a file-conflict report here, which lists game files that more than one mod writes and which mod ends up winning. Fix what the report finds, then validate again.

4. Install

When validation passes, install. The progress page moves on as each mod finishes. Stop Install asks you to confirm, then stops at the next safe point. If something fails, the page offers Restore to put your folders back from the snapshot. See Safety and recovery.

If the guide has widescreen-only mods, they install as a separate step after the main build.

Getting the mods

Most KOTOR mods live on Deadlystream or Nexus Mods. Those pages, and MEGA links, open in your browser: the app shows each mod's links so you can download them yourself.

The desktop's Downloads panel can fetch the links it knows how to download, and lists the rest with the reason and a link to open. Direct downloads are checked before they are saved: a web page instead of an archive, a damaged archive or a wrong checksum fails, and an existing file is never overwritten.

Mods that use a patcher

Many KOTOR mods come with a TSLPatcher-style installer instead of plain files. ModSync.rs can run that patch step for you, but only after you allow outside programs to run. That permission is off by default, because an outside program runs with your user's permissions.

Windows programs need a Windows computer. ModSync.rs does not run them through Wine for you.

Save your setup

A profile remembers a guide, your folders and your mod choices. In the desktop, expand Install profiles, enter a name and press Save current profile. Later, Activate profile brings those choices and folders back. Run validation again before installing.

The Theme menu offers Light, KOTOR and KOTOR 2 looks, and remembers your pick.
