Features and roadmap

What ModSync can do today, and what is coming next.

At a glance

The desktop app and the command line share one engine for choosing mods, checking them, unpacking archives and installing. Whichever you use, a guide installs the same way.

Every commit is built and checked automatically on Linux, with a Windows cross-check. Full Windows and macOS builds run for each release.

Installing a big mod build changes a lot of files. ModSync keeps a snapshot it can restore, but keep your own backup of your game folder too. See Safety and recovery.

That proves the files can be read, not that the builds install correctly. Beyond that, the desktop app has installed the sample guide on Linux, patcher runs have installed test files into isolated folders, and a direct download was checked against its expected checksum.

The desktop apps

The desktop app for players lives in desktop/tauri. It follows the KOTOR Mod Manager design and runs every check, download and install through the ModSync engine. For community builds whose guides only describe the steps in prose, it ships install steps for the KOTOR 1 Full Build and works out the rest from each mod's download, then checks each one before it is used.

The built-in ModSync window (modsync gui) stays available. A desktop app built with Qt is also being developed, mainly for guide authoring.
