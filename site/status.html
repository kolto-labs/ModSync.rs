Compatibility and status

ModSync.rs is an initial implementation, not a verified replacement for every feature of the original C# ModSync. This page says plainly what works and what has not been proven.

Where it stands

The desktop app and the command line share one engine for selection, validation, archives and installation. Many features of the original app are in place, and the project keeps a detailed record of each one and its limits.

No full build has been verified yet. Nobody has yet installed a complete KOTOR 1 or KOTOR 2 build with ModSync.rs and compared it against a careful manual install, launched the game and played it. Treat it as early software and keep backups.

Automatic checks build the app and run strict lint checks on Linux, including a Windows cross-check. Native Windows and macOS builds run on request. These checks prove the code builds, not that every feature matches the original.

What has been tested

All eight existing TOML build files load without errors:

KOTOR1_Spoiler_Free109

KOTOR2_Full145
KOTOR2_Spoiler_Free99
KOTOR2_Mobile_Full105

That proves the files can be read, not that the builds install correctly. Beyond that, the desktop app has installed the sample guide on Linux, patcher runs have installed test files into isolated folders, and a direct download was checked against its expected checksum.

The desktop apps

The current desktop app is the default one you get from the build. A new desktop app built with Qt is being developed alongside it, mainly for guide authoring. It is a partial replacement under development, and the current app stays the default until it can do everything the current one does.
