Questions, answered

Short answers to what players ask most.

Common questions

What is ModSync.rs?

A desktop app and command line tool that installs KOTOR 1 and KOTOR 2 mod builds by following a guide's instruction file. It is a Rust version of ModSync, and it does not need .NET.

Is it a mod build?

No. ModSync.rs contains no mods. A mod build, and its instruction file, comes from a guide author. ModSync.rs reads that file and carries out its steps on your computer.

Does it replace the original ModSync?

Not yet. It is an early implementation, not a verified replacement for every feature of the original C# app. See Compatibility and status for what works today and what is still missing.

Which games does it support?

KOTOR 1 and KOTOR 2. It detects KOTOR 1, the original KOTOR 2 release and the newer Aspyr release of KOTOR 2, and leaves out Aspyr-only mods on a copy that is not the Aspyr release.

Will it download the mods for me?

Partly. Deadlystream, Nexus Mods and MEGA pages open in your browser and you download from there. Direct download links can be fetched for you, and are checked before they are saved.

Is my game safe?

Validation never changes your folders. Before installing, ModSync.rs copies your game and mod folders, and if the install fails you can restore that copy. Still keep your own backup. Read Safety and recovery.

An install failed. What now?

Restore first (the Restore button, or modsync restore), fix the cause, then run the whole guide again from the start. Do not install the failed mod on its own at the end.

Can it run TSLPatcher mods?

Yes, once you allow outside programs to run. That permission is off by default. Validation cannot predict what a patcher will change, so a clean validation report does not guarantee the patch step will succeed.

Does it work on Windows, macOS and Linux?

It builds on all three. Linux gets the most testing; native Windows and macOS builds are checked less often. Windows-only patchers need a Windows computer.

Where are my settings and profiles kept?

In a ModSync folder in your system's settings location: the XDG config folder on Linux, Application Support on macOS, and roaming application data on Windows. You can choose a different folder.

I found a bug. Where do I report it?

Open an issue on GitHub. Say which guide you used, which mods you picked and what the report or log said.
