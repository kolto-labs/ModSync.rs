ModSync/For players/Troubleshooting

When something goes wrong

Find the step where your problem showed up, then look for the message you saw. Each entry explains what it means and what to try. In the messages below, words in capitals stand for a name, such as a file, a mod or a folder.

Loading a guide

These problems happen when ModSync opens the guide, before you choose any mods.

The guide file will not open

You may see Input file not found: PATH. ModSync cannot find the file at the location you gave it. Check the file name and the folder, then choose the file again.

An unknown field or action stops the guide

ModSync reads only the fields and actions it knows about. When it meets one it does not recognise, it stops instead of skipping it. You may see Unsupported action ACTION; refusing to skip it, or an error saying a field is unknown. Usually the guide was written for a different version of ModSync, or it contains a typo. Make sure you have the latest ModSync. If the error stays, tell the guide's author.

The guide is in a format ModSync does not read

ModSync reads guides in TOML, JSON, YAML, XML or Markdown. A file in any other format stops with Unsupported instruction format: FORMAT. Check that you opened the guide itself, and not a web page or some other download.

The guide has no mods in it

You may see The guide has no components, or, for a Markdown guide, Markdown has no component sections or structured guide blocks. The file opened, but ModSync found nothing it can install. This is a problem with the guide, so ask its author for a corrected version.

Choosing mods

These problems come up when you tick mods and pick options.

A mod needs another mod that is not selected

You may see Cannot install 'MOD' due to 'OTHER' not being selected for install. The mod you picked depends on the other one. Select the mod it names, then check again.

Two mods you picked cannot go together

You may see Cannot install 'MOD' due to 'OTHER' being selected for install. The guide says these two mods conflict. Untick one of them.

A dependency is missing from the guide

You may see Required dependency is absent from the guide: NAME. A mod needs something the guide does not include, so it cannot be installed as written. Ask the guide's author to fix it.

An option cannot be found

You may see Unknown option ID. The guide refers to an option that does not exist in it. Report it to the guide's author. Do not try to edit the guide yourself unless you know what you are changing.

Installer choices are still waiting

You may see FOMOD choices pending: N queued. Finish or dismiss these before validation or installation. Some mods use an installer with its own choices, and ModSync is waiting for you to answer them. Finish the installer prompts for each queued archive, or dismiss them, and then validate again.

The install order goes in a circle

You may see Circular dependency detected, or a message saying a circular InstallBefore/InstallAfter order cannot be resolved. Two or more mods each say they must install before or after the others, so there is no valid order. This is a problem with the guide. Report it to the guide's author.

Validation

Validation checks the guide, your selections and the archives before anything is written to your folders. A problem found here is safe to fix at your own pace.

A required archive is missing

You may see Missing Required Archives: [NAME] or Missing required archive: NAME. The guide needs an archive that is not in your mod folder. Download it, either with Fetch Downloads or from the link in the guide, and put it in the mod folder. The validation report suggests you verify that the archive exists and is not corrupted, and try downloading it again from the mod link.

A file cannot be found inside an archive

You may see Failed to find 'FILE' in any archives. The archive is there, but it does not contain the file the guide asks for. It is often the wrong version of the mod. Check that the archive matches the version the guide names, and download it again if you are not sure. The report may also say The required file is missing. This may indicate an incomplete mod archive or incorrect source path.

A checksum does not match

You may see SHA-256 mismatch: the present file FILE does not match this component's ContentHashSHA256; it was not replaced, or SHA-256 mismatch; download discarded. The checksum is a fingerprint of the exact file the guide expects. A different fingerprint means you have a different file, or a download that was damaged or cut short. Download the archive again, or get the version the guide names. Do not change the checksum in the guide to make the message go away, because that removes the check.

An archive is corrupt or is not an archive

You may see Could not open archive or Not an archive. The file is damaged, incomplete, or is a web page or something else saved with an archive's name. Delete or move the bad copy out of the mod folder, then download the archive again. ModSync will not overwrite a file that is already there.

A path is refused as unsafe

You may see Unsafe path: PATH, Absolute path is forbidden: PATH, Reserved filename: PATH, or Path must start with <<modDirectory>> or <<kotorDirectory>>: PATH. The guide asks for a location outside the game and mod folders, or uses a name Windows reserves. ModSync refuses these rather than guess where the file should go. This is a problem with the guide, so report it to its author.

The game or mod folder cannot be found

You may see Game directory not found: PATH or Source directory not found: PATH. The folder you chose does not exist any more, or was typed wrongly. Choose the folders again. The game folder is the one that contains your KOTOR game, and the mod folder is where your archives are kept.

An Aspyr-only mod is refused, or the game version is unknown

You may see 'MOD' (ID) is Aspyr-exclusive and cannot be selected for this game, or Game version unknown; left N Aspyr-exclusive mod(s) selected. Some KOTOR 2 mods only work with the newer Aspyr release. When ModSync knows your copy is not that release, it removes these mods from your selection and tells you so. If it cannot tell which version you have, it leaves them selected. Check that your game folder is the right game and version, and untick any Aspyr-only mod you do not want.

Downloads

Fetch Downloads gets archives for you where it can. Some hosts need you to download by hand in your browser, and that is normal.

The download saved a web page instead of an archive

You may see Server returned a web page. Use the host's browser download flow. The link led to a page that asks you to do something first, not to the file itself. Open the link in your browser, download the archive from there, and put it in your mod folder. ModSync checks what it downloads and refuses web pages.

A file already exists and was not downloaded again

You may see Download destination already exists. ModSync never overwrites a file you already have. If the file is good, you do not need to do anything. If you want a fresh copy, move or delete the old file first, then download again.

A host needs a login, a CAPTCHA or a wait

You may see Host requires a login, Host requires a browser challenge, Host requires a timed or free-user download, or Host download is not automated, each followed by open it in a browser. Open the link in your browser, complete the steps the site asks for, and put the downloaded archive in your mod folder.

Nexus, DeadlyStream and MEGA links are browser downloads

Nexus Mods pages, DeadlyStream pages and MEGA links are usually downloaded in your browser. For Nexus, Fetch Downloads uses your Nexus API key to get the file. If you see Nexus API key is missing, invalid or unauthorized, check the key you entered, or download the file in your browser instead.

A MEGA download is refused or delayed

ModSync reports MEGA's own error codes. What to do depends on the message:

  • MEGA transfer quota exceeded (-17), MEGA bandwidth limit reached (HTTP 509) or MEGA rate limit reached (-4): MEGA is limiting downloads for now. Wait and try again later, or download the file in your browser.
  • MEGA denied access to this file (-11): open the link in your browser.
  • The MEGA file was not found (-9): the link may have been deleted. Ask the guide's author for a new one.
  • The MEGA file is blocked or was taken down (-16): the file is no longer available from MEGA, so ask the guide's author for another source.
A torrent download fails because there is no working proxy

You may see No working proxy; explicit Resume or restart required. Peer downloads go through a proxy by default, so other people cannot see your address. If none of the proxies work, ModSync stops and does not connect to peers directly. Try again later, or give ModSync a proxy you trust in the peer proxy setting. The command line can also be given one with --peer-proxy.

A torrent does not match the guide

You may see SHA-256 mismatch; torrent discarded, TorrentInfo hashes to ... or ModSync torrents must contain exactly one archive. The torrent you got does not match the one the guide describes, or the file inside it is not the expected archive. ModSync throws the download away and does not keep it. Check that you copied the link and the info code from the guide exactly, and ask the author if it still fails.

Patchers and programs

Some mods run a patcher, which is a small program that changes game files. Validation never runs these programs, so a clean validation report does not promise that a patcher will succeed.

External programs are switched off

You may see Patcher needs explicit trust: enable external programs (--allow-processes), or the same message with another action name, such as Execute or Run. External programs are off by default. Turn on the external programs switch for this install and try again. Only do this for guides you trust, because these programs run with your own user permissions.

The patcher cannot be found

You may see Configured patcher is not an executable regular file: PATH or Configured patcher path is unavailable. The patcher setting points at something that is missing, is a folder, or is not a program. Choose the patcher program again, making sure you pick the program file itself.

A Windows-only program will not run on Linux or macOS

You may see Windows Execute requires explicitly configured headless Wine runner. Windows programs need a Windows computer. ModSync does not run them through Wine by itself. Run the install on Windows, or use a version of the patch made for your system if the guide author provides one.

A patcher failed during the install

You may see Patcher install log reported errors, or Patcher install log not found at invocation root PATH (expected installlog.rtf or installlog.txt). The patcher writes an install log, and ModSync copies the error and warning lines from it into the progress log during the install. On the Installing page, the Copy Log button copies that log. The error message itself names the first errors found.

Look at those lines to find the cause. Then restore the snapshot, fix the cause, and run the whole guide again from the start, as described in Restoring.

Installing

Installing validates first, then makes a snapshot of your game and mod folders, and then does the work. These are the messages you may see while it runs.

The install stopped partway through

ModSync stops at the first failure and reports Install stopped. Restore before retrying. Nothing after that point runs. Restore first, following Restoring, then fix the cause and run the install again from the top.

An unfinished install blocks a new one

You may see An unfinished install exists. Run restore before retrying. ModSync will not start a new install on top of a half-finished one. Restore first, and then install again.

Another ModSync process is using the folder

You may see Another ModSync process is using this game or mod directory. Two copies of ModSync, or a ModSync command and the desktop app, are trying to change the same folder. Close the other one, wait for it to finish, and try again. Also leave the game and mod folders alone in other programs while an install or restore is running.

There may not be enough disk space

ModSync has no single message for running out of space, so you may only see a general error from Windows, Linux or macOS. The snapshot is a full copy of both your game folder and your mod folder, and it is stored beside the game folder. Free up space on the drive that holds your game. If unpacking archives is the problem, you may see Archive exceeds expanded-byte budget or available scratch space. In that case, choose a different temporary storage folder under Archive storage, or use --scratch-dir on the command line.

A folder is not writable

You may see Installation blocked before any write: The Mod directory is not writable!, or the same message for the install directory. ModSync cannot write to that folder, so nothing has been changed. Run ModSync with administrator rights, or choose a folder you have permission to write to.

Restoring

Restore puts your game and mod folders back the way they were before an install that did not finish. It only works on an unfinished install. It checks the snapshot before it touches either folder, and checks the restored files afterwards. From the command line it looks like this:

modsync restore --game-dir /path/to/game --source-dir /path/to/mods

Use the same game and mod folders as the install that failed. In the desktop app, use Restore on the progress page.

Restore says there is nothing to restore

You may see There is no unfinished install to restore. Restore only deals with an install that did not finish. An install that completed is not undone by restore. If the game is not working, see After installing.

Restore refuses because the snapshot does not match

You may see Snapshot hashes differ; refusing to restore. ModSync checks the snapshot against the fingerprints it recorded before it changes anything, so nothing has been restored. Do not copy files into the snapshot folder or change it by hand. Keep the .modsync- folder as it is, and report the problem with the details listed in Reporting a problem.

A restored file did not match

You may see Restored hash mismatch: FILE. Restore copied the files back, but one of them did not match its fingerprint afterwards. Stop and do not install anything else. Replace that file from your own backup if you have one, and report the problem. Keep your own backup of anything valuable, such as save games.

Restore points at the wrong folders

You may see Recovery roots do not match this install. The game or mod folder you gave restore is not the one the install used. Run the restore again with the same two folders you installed into.

After installing

If the game will not start or crashes, first find out whether the install finished.

The game crashes after an install that failed

If the install stopped with an error, restore first, then fix the cause and run the guide again from the start, in the guide's order. Do not install the failed mod on its own at the end. Mods later in a guide often overwrite or build on files from earlier ones, so adding a failed mod to the end can undo other mods or break the game.

The game crashes after an install that finished

Restore cannot undo an install that completed, so the snapshot will not help here. Check the guide's order against the mods you selected. If you have your own backup of the game folder, use it to return to a clean copy before you install again. Then report the problem with the details listed in Reporting a problem.

Reporting a problem

If none of this helps, the guide's author or the ModSync team can usually sort it out quickly if you include the following:

  • The guide: its name, and where you got it.
  • The mods you selected: the list of mods and any options you chose.
  • The validation report or the log: copy the message you saw and the error and warning lines from the log.
  • Your operating system: Windows, Linux or macOS, and its version.
  • Your ModSync version.

Remove any personal details, such as your user name, from file paths before you share them. Then open an issue on GitHub.
