Your first full build

A step-by-step walkthrough for installing a full KOTOR mod build for the first time. Follow the steps in order and you will end up with a working game.

Before you start

A full build is a long list of mods that install in a set order. Spend a few minutes getting ready. It saves a lot of trouble later.

  • A clean game install. Build instructions assume a fresh game. ModSync's welcome screen says the same thing: start with a clean KOTOR install. If you installed mods by hand before, uninstall and reinstall the game first.
  • The right game version. Each build's guide says which game and release it is for. ModSync looks at your game folder and reports what it found, on the game folder step, as Detected game. For KOTOR 2 it can tell the Aspyr release apart from the others. Some mods only work with the Aspyr release. If your game is not Aspyr, ModSync turns those mods off for you. If it cannot tell which version you have, it leaves them on and shows a warning.
  • A backup. Copy your game folder somewhere safe before your first big install. The snapshot ModSync makes is there to undo a failed install. It is not a copy to keep.
  • Free disk space. Before it installs, ModSync makes a full copy of your game folder and your mod folder. You need room for both.

Read the notices. If the guide has Aspyr notes, ModSync can show them on an Aspyr Version Notice page. Read them before you go on.

Get the instruction file

The KOTOR Community publishes mod builds at kotor.neocities.org. The instruction files are also in the public repo at kolto-labs/mod-builds. Download the instruction file for the build you want and save it somewhere easy to find, such as your Downloads folder.

The instruction file tells ModSync which mods are in the build and how each one installs. ModSync reads TOML, JSON, YAML, XML and Markdown instruction files. It does not come with any mods.

Download the mods

Most KOTOR mods are on Deadlystream or Nexus Mods, and some are on MEGA. Those pages open in your browser. You download the files yourself, and ModSync checks them once they are in the right folder.

  1. Make one folder for all the archives. This is your mod folder. Keep it separate from your game folder.
  2. Open each link from the build's guide page and download the file. Some sites ask you to sign in or wait a few seconds first.
  3. Save every archive into that one mod folder. Keep the file names as they are, and do not unzip or rename the archives unless the guide tells you to. ModSync opens archives itself.

Not sure which link goes with which mod? Pick your mods in ModSync first. The Selected mod sources panel then lists the links for every mod you selected.

ModSync also has a Downloads panel. Nothing downloads automatically. When you select Fetch Downloads, it fetches the archives it can get directly, keeps the ones you already have, and leaves the rest for your browser. Sites that need a login, a CAPTCHA or a wait stay manual.

On the command line there is no step for browser downloads. Use modsync download only for a direct download link, as shown in the command line guide.

Open ModSync and load the guide

Open ModSync. If you still need to install it, see Getting started.

  1. On the Load an instruction file screen, click Load guide. Pick the instruction file you downloaded.
  2. Check that the guide loaded. The welcome screen shows how many components it found.

When the guide is loaded, click Next to start the step-by-step wizard. Use Back to return to an earlier step.

On the command line, you can list the mods in a guide before you install anything:

modsync list KOTOR1_Full.toml

Choose your game and mod folders

  1. Game folder. Choose the folder that holds your KOTOR game and its Override folder. The wizard step is titled KOTOR Game Directory, and the field is labelled Game directory.
  2. Mod folder. Choose the folder with your archives. The step is titled Mod Workspace Directory, and the field is labelled Mod directory. The app asks you to keep it separate from your game installation.
  3. Use Browse… next to each field if you do not want to type the path.
  4. Tick Save directories for next launch if you want ModSync to fill these in next time.

The two folders must not overlap. ModSync refuses a game folder and a mod folder that overlap, and it refuses paths that point outside them.

On the command line, these are the --game-dir and --source-dir options, shown in the steps below.

Pick mods and options

On the Mod Selection step, tick the mods you want. A few tools help with a long list:

  • Select through tier and Select category add a whole group at once. Tiers add up, so choosing tier 3 also selects tiers 1 and 2. Optional is its own tier.
  • Select multiple categories… lets you tick several categories and apply them together.
  • Select all, Deselect all and Clear filters do what they say.
  • Spoiler-free names and descriptions swaps in text without plot details, where the guide provides it. It only changes the names and descriptions you see.

Dependencies are added for you. If a mod you pick needs another mod, ModSync selects that one too and logs the change.

Some mods have options, which are extra choices such as a texture or a tweak you can turn on. Tick the ones you want. Options keep the defaults the guide sets.

Some mods ask you to answer their own installer questions. When one does, a window opens showing Step X of Y, with Next, Back and Use these choices. Work through each step and then choose Use these choices.

Widescreen-only mods are a separate phase. They install after the main build, and the bulk selection buttons leave them alone.

On the command line, ModSync selects every top-level mod by default. To pick your own mods, use --use-file-selection or --select. The command line does not add dependencies for you, so select those yourself.

modsync validate --input KOTOR1_Full.toml --game-dir /path/to/game --source-dir /path/to/mods \
  --select "Mod Name" --option OPTION_GUID

Run validation and read the report

Click Run validation. Validation walks through the whole install without changing your files. The app describes it as simulating file changes, so nothing in your game or mod folder changes yet.

The Validation report shows counts for Errors, Warnings and Passed. Use Go to first issue to jump to the first problem, or Copy validation report if you want to share the report when asking for help.

  • Errors must be fixed before you install.
  • Warnings are worth reading. Check each one before you decide whether it matters.

These are the messages you are most likely to see, and what to do about them:

What you seeWhat it usually meansWhat to do
Missing required archive: ... or Missing Required Archives: [...]The guide expects an archive that is not in your mod folder, or the file has a different name than the guide expects.Download the missing archive into the mod folder, using the file name the guide shows. Then run validation again.
WARNING: ...: missing dependencies: ...A mod you picked needs another mod that is not selected.Select the mod it names, or deselect the mod that needs it.
Required dependency is absent from the guideThe guide itself is missing a mod it depends on.Ask the build's author. Changing the guide yourself is not recommended.
... is Aspyr-exclusive and cannot be selected for this gameThe mod only works with the Aspyr release of KOTOR 2, and your game is not that release.Leave that mod off, or check that you have the right game version.
duplicate files/folders ... in a case-insensitive environmentYour game folder has two copies of a file or folder whose names differ only by capital letters. This often comes from an old manual install.Check the output for the names listed. Keep a backup, then remove the extra copy. If you are unsure, ask the build's author before you continue.
Some components failed to validateOne or more mods failed. The message suggests a missing download, or an antivirus program blocking ModSync or HoloPatcher.Read the lines under it. Fix the missing downloads first. If files are being blocked, allow ModSync in your antivirus.
Missing external program/mod or Patcher install log not foundA patcher step needs a program or file that is not set up yet.Set up the patcher as described in Allow patchers, then run validation again.

After you fix something, run validation again. A passing report is not a promise of a perfect install, and the report says so. Patchers run only at install time, so validation cannot tell you what they will do.

Analyze conflicts is optional. It lists game files that more than one mod writes and says which mod ends up winning. Choose Show conflict details to read the list. Read the limitations shown with it.

On the command line:

modsync validate --input guide.toml --game-dir /path/to/game --source-dir /path/to/mods
modsync validate --input guide.toml --game-dir /path/to/game --source-dir /path/to/mods --json
modsync conflicts --input guide.toml --source-dir /path/to/mods --game-dir /path/to/game

Allow patchers if the build needs them

Many KOTOR mods come with a patcher, a small installer program that changes game files. ModSync can run those patchers for you, but only after you give permission.

  1. On the validation screen, tick Trust this guide to run external programs.
  2. If the guide asks for a specific patcher, set Patcher backend and Patcher executable, then choose Save patcher setting. Otherwise leave these alone.
  3. Run validation again.

Only tick the trust box for a guide you trust. The box is off by default. A program you allow runs with your own user permissions.

Windows patcher programs need a Windows computer. ModSync does not run them through Wine for you.

On the command line, the trust option is --allow-processes:

modsync install --input guide.toml --game-dir /path/to/game --source-dir /path/to/mods \
  --allow-processes --patcher /path/to/odypatcher

Install and watch the progress

  1. When validation has passed, click Install selected mods.
  2. A window titled Install selected mods? explains that the snapshot needs room for both folders and that the install stops at the first error. Click Create snapshot and install to go ahead, or Cancel to go back.
  3. The Installing Mods screen shows progress. It says Please wait while mods are being installed... and each mod is marked as it finishes.
  4. When the base build is done, the Base Installation Complete screen appears. If you chose widescreen mods, they install next, after the Widescreen Support step.
  5. The Installation Complete screen means you are finished.

To stop part way through, click Stop Install. ModSync asks Stop the install?. Choose Stop install to stop, or Keep installing to carry on. The install stops at the next safe point.

On the command line, a single command validates, makes the snapshot and installs:

modsync install --input guide.toml --game-dir /path/to/game --source-dir /path/to/mods

If something fails

ModSync stops at the first failure and marks the install as unfinished. It will not start another install on top of a half-finished one.

  1. Restore first. On the progress screen, click Restore snapshot. You can also use Restore failed install on the validation screen. Restore checks the snapshot before it touches either folder, puts your files back, and then checks them again.
  2. Fix the cause. Most failures come from a missing or wrong archive. Read the validation report and the messages in the table above.
  3. Start again from the top. Run validation, then install again in the guide's order.

Never add a failed mod to the end. Mods later in a build often overwrite or build on files from earlier ones. Installing an early mod last can undo later mods or break the game. Restore, then rerun the whole guide.

On the command line:

modsync restore --game-dir /path/to/game --source-dir /path/to/mods

For more on how the snapshot works, see Safety and recovery.

After installing

Launch the game and check that it starts. Try a few places where your mods change things, such as a new texture or a changed area.

ModSync keeps the snapshot from your last successful install until your next install replaces it. Keep it for a while, until you are happy that the game works. The snapshot is not a backup, so keep your own copy of anything valuable, such as your save games.

If you add or remove mods later, run validation again before installing, so ModSync checks the new set of mods first.
