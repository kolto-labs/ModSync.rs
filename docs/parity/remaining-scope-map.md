## Required work outside the C# feature count

Default-on proxy-only peer sharing remains a user requirement even though pinned C# lacks it. [P2P plan](p2p-acquisition-plan.md) has seeding identity/privacy/stop-policy contracts; current fetch/desktop slices explicitly exclude a persistent finished-download sharing lifecycle. The independently approved [persistent-sharing plan](persistent-sharing-plan.md) now defines lifecycle, durable CLI admission, fair active-time budgets, UI ownership, exit/Stop/install handoff and exact proof. Implementation remains open. Persistent sharing must not disappear because it lies outside F01–F29. Guide hash/magnet field-writing support is a documented follow-up to reconcile with existing authoring capability: the plan already specifies `torrent-seed` plus copying its printed identity into the guide. The deferred editor/CLI helper is not established here as a separately mandatory new feature.
