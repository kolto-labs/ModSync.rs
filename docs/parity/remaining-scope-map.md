Implementation remains open. Persistent sharing must not disappear because it lies outside F01–F29. Guide hash/magnet field-writing support is a documented follow-up to reconcile with existing authoring capability: the plan already specifies `torrent-seed` plus copying its printed identity into the guide. The deferred editor/CLI helper is not established here as a separately mandatory new feature.
