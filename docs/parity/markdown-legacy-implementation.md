# M2 legacy bullet metadata implementation

## Source contract

`markdown/legacy.rs` reads the bounded legacy grammar from pinned C# `src/ModSync.Core/Parsing/MarkdownParser.cs:1001-1293`. The Markdown component seam selects this parser only when the first nonblank metadata line starts with the exact component `- **GUID:**` marker or is exactly `#### Instructions` or `#### Options`. Otherwise existing TOML/YAML handling remains authoritative. Failed structured parsing never falls back to legacy parsing; mixed syntax is rejected.

Component GUID is optional and precedes the section markers. The existing generated prose component GUID is retained when absent. Instructions precede Options. Numbered `**GUID:**` headers delimit ordered top-level instructions; these obsolete instruction GUID payloads are ignored. Top-level instruction properties use `**Action:**`, `**Overwrite:**`, `**Source:**`, and `**Destination:**` without a bullet. Source lists split on commas, trim items, and omit empty items.

Case-insensitive `#... Option <number>` headings introduce one level of options. Supported option properties are the exact bulleted labels GUID, Name, Description, Is Selected, Install State, Is Downloaded, and Restrictions. Missing option GUIDs receive generated UUIDs, matching the reference's structural rather than byte-identical identity behavior. Restrictions are parsed as GUID lists. Option instruction blocks start at `- **Instruction:**` and use bulleted Action/Overwrite/Source/Destination properties, with obsolete bulleted instruction GUIDs ignored. The next instruction marker, option heading, or recognized option property ends an instruction block. Repeated instruction markers create ordered sibling instructions, not nested executable options.

Actions are case-insensitive known executable actions; `Unset`, unknown actions, and missing Action fail. Explicit boolean values must be true/false. GUIDs must parse; supported Install State values are 0 through 5. Contradictory duplicate properties fail; equivalent repeated properties are accepted after typed conversion. Instructions other than DelDuplicate must have nonempty Source; Copy, Move, and Rename additionally require a nonempty Destination. Extract retains the existing default destination when omitted; DelDuplicate does not require Source because its engine operation is destination-based. Unsupported properties, incorrect field bullet syntax, reversed/duplicate sections, arbitrary extra prose, malformed values, and truncated instructions fail with metadata line diagnostics. Arguments, Dependencies, and deeper option nesting are not silently accepted as executable behavior.

The parser returns ordinary component data through `Guide::from_value`, including the existing final component load. It neither changes execution roots nor bypasses source normalization. Non-Choose Source paths therefore receive the same safe normalization as structured Rust inputs. Choose Source strings remain the authored trimmed comma-list values under the case-insensitive action exclusion; the shared engine validates their referenced option identities. Component and option GUIDs use canonical UUID text. No parser-local path interpretation or execution is added. Current prose/metadata merge behavior and the outer loader's component selection defaults remain in place. Option selection defaults to the existing model default when omitted.

## Deliberate strict differences and limits

Pinned C# legacy setters preserve raw Source strings; Rust retains the approved uniform normalization. Stored Source text equivalence and downstream execution equivalence are separate, currently unverified claims. Paths are subjected to the existing engine containment checks before installation; parsing alone does not establish a valid executable install.

C# silently defaults or discards malformed actions, booleans, GUIDs, states, properties, and incomplete instructions. Rust rejects these conditions. Rust also rejects missing required instruction fields and unrecognized text instead of constructing an empty/default executable record. Obsolete instruction GUID payloads remain ignored as required by the legacy grammar. The option instruction marker must start the trimmed line; C#'s substring match is not used to treat an arbitrary property value as an instruction marker.

Omitted valid option IDs remain nondeterministic UUIDs and require structural mapping in future comparison receipts. Legacy instructions carry no Arguments or Dependencies fields because those are outside the reference bullet grammar. Runtime Install State and Is Downloaded option values are retained as metadata; parsing them does not itself mark execution complete or prove files exist.

## Verification boundary

Only source inspection against pinned C# was performed. No tests, fixtures, custom harnesses, builds, Cargo commands, CI, or production/runtime invocations were created or run for this slice, and existing inline tests were not edited.

Independent source review and parent-owned production compilation/lint remain required. The M2 controlled acceptance matrix remains deferred: CRLF and blank lines, each property and action shape, absent versus invalid values, contradictory duplicates, repeated option instructions, unsupported nesting/fields, malformed structured inputs, multiple options, Choose identities, safe and unsafe paths, cross-format conversion and Rust/C# stored-model comparison. A real generic Copy/Choose install, untouched outside-root sentinel, malformed-input pre-mutation rejection, and raw-C# versus normalized-Rust execution comparison are still required before downstream parity can be claimed.
