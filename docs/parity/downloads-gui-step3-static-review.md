Remaining-phase validation uses `CompletionContext::Retained` and `validate_report_remaining_observed`; the next remaining-phase install uses `install_remaining_observed` (`src/ui.rs:3059-3075,3500-3529`). Footer `WidescreenModSelection` still asks for snapshot/install confirmation when mods are selected (`src/ui.rs:1429-1435`). This meets the reviewed G7 recovery and phase-order requirement.
