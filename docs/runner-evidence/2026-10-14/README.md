# Linux runner evidence — 2026-10-14

The CLI and native GUI GitHub jobs in `runs.json` passed on temporary Linux
self-hosted session runners. Each workflow checked out its recorded source and
public guide revisions and rebuilt the production target before verification.

K1 and TSL use original synthetic payloads projected from supported action
families in the pinned `full.md` corpus. CLI receipts record draft rejection,
no-write validation, source-owner preservation, final SHA-256 manifests and
completion order. GUI receipts add seven actual native mouse clicks per game,
visible validation and installation terminals, screenshots and final byte checks.

The production gate receipt covers formatting, lib/bin builds and strict Clippy
in both feature modes. Rust test targets and custom Rust harnesses stayed frozen.
Different CLI/GUI builds have separately recorded binary hashes.

Receipts are curated: source-owner names in draft-added owner metadata are
redacted, while addresses, counts and hash/order results are retained. Raw guide
conversions and full coverage inventories remain in the session runner workspace,
outside this repository. No game files, mod downloads or external patcher runs
are represented as verified here.

GitHub-hosted Windows/macOS jobs were dispatched but rejected before allocation
for account billing. Session Azure artifact/log storage was denied by the network
proxy; these safe receipts and screenshots preserve the available evidence.
Hosted workflow artifact upload remains required; session mode explicitly retains
proof in the provisioned workspace.
