# Changelog

## [0.1.0]

### New
- KOTOR Mod Manager now runs on the ModSync engine. Pick a community mod build or open an instruction file, choose your mods, get their files, check them and install.
- Keep several game installs, each with its own folders and mod choices.
- Installed mods can be turned off and on again, and the game can be put back to how it was before any mod.
- See which installed mods write the same files or should not be combined.
- The app can find your KOTOR install for you and walks you through the first setup.
