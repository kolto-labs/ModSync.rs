  ## 2. Virtual filesystem / prediction

  adds `Engine::predict(self, &Guide) -> Result<Prediction>` (engine.rs ~459).
    - It runs `recovery::ensure_clean`, `fomod_gate` and `run` in the same
  simulation mode as validation.
    - It returns `Prediction { entries: Vec<PredictedEntry{path, directory,
  content_known, bytes: Option<u64>}>, events: Vec<Event> }`, sorted by path.
    - `Session::predict(settings, component, instructions)` in
  `src/editor/easy.rs` calls it. It truncates component N's instructions to the
  first K, deselects every later component (`is_selected = false`), and refuses

  - Actions are the 12 names in `src/model/action.rs`: Unset, Extract, Execute,
  Patcher, Move, Copy, Rename, Delete, DelDuplicate, Choose, Run, CleanList. The
